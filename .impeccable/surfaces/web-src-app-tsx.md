# Evidence console

Mode: Operate.

The user asked for a very premium, technically expressive interface. A dark graphite debugger workbench is the selected direction, with an equivalent light theme for long reviews in bright rooms. The theme preference question was optional and unanswered; both themes are implemented.

The work sequence is locate an assessment, inspect uncertainty, trace a finding to configuration evidence, then review a mapping or proposal. The user subsequently requested a much richer interface with micro-interactions and explicitly chose "Use your judgment and continue." The existing world is amplified across the whole workspace: an inset collapsible navigation dock, an animated active marker, a real-data control spectrum and an adjacent finding preview establish the first viewport. Finding and source panes carry the identity deeper in the application.

Grounded candidates considered: packet trace viewer; electronic instrument rack; engineering change dossier; maintenance fault-isolation manual; forensic bench; signal analyzer; debugger workbench. Selected candidate 7, concept seed b6d4e010. This is a custom grounded direction; no catalog quality card or user-approved image comp exists.

DESIGN.md records the shared tokens. Geist provides readable dense UI text; its font-popularity detector warning is accepted deliberately for this operational surface. Technical expression comes from evidence adjacency, restrained code panes, measured values and real processing state. No invented network graph, traffic, health indicator, benchmark certification, or AI confidence score.

Keyboard navigation, visible selection, honest loading/error states, role gates, reviewed changes, redaction and synthetic labels remain part of the contract. Mobile stacks the panes and keeps wide tables in labelled local scrollers. Light and dark themes persist across reloads.

The control spectrum is the authored interaction. Hover previews, click/focus pins, and the resulting link opens the exact finding. An Explore in 3D entry on the overview, audit header and audit rows makes the spatial debugger easy to discover. Native layout transitions, copy feedback, file chips, drag states and restrained control feedback support that focal interaction. Motion is bounded, interruptible and optional; no ambient effect is introduced. See docs/rich-ui-plan.md for the interaction contract.
