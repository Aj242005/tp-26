# Design

The application is an evidence workbench. A network administrator uses it during daylight office work, often beside configuration documents; a quiet light canvas and dark navigation keep dense evidence readable.

Use a restrained graphite, white and blue palette. Blue identifies an action or selection; severity uses labelled amber/red/green treatments. The main view is a working register with filters and real results, not a marketing dashboard. The signature interaction is selecting a finding and seeing its exact configuration evidence, rule and proposed change together.

System UI font for controls and prose; system monospace only for configuration, identifiers and measured values. Body 14–16px, page title 28–32px, section title 18px. Spacing 4/8/12/16/24/32/48px. Borders delineate registers; no decorative gradients, glows or fabricated charts. Corners 8px on controls, 12px on major surfaces.

Desktop: persistent 224px navigation rail, compact top context bar, wide register and split evidence view. Mobile: compact horizontal navigation, stacked evidence, tables in labelled horizontal scrollers. States explicitly distinguish loading, empty, failed, waiting for review and complete. Reduced motion is respected; evidence selection uses a brief background transition.

Tokens and details will be updated after visual verification. Product/workflow truth comes from the approved plan; visual choices are implementation decisions within that authorization.
