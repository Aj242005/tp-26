# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Network administrators, security auditors and mapping reviewers investigating heterogeneous device configurations. Confirmed through the supplied statement and approved implementation plan.

## Product Purpose

Turn configuration snapshots into inspectable compliance findings and reviewed remediation proposals. Learn unfamiliar configuration formats through tested, versioned mappings without backend deployment.

## Operating Context

Local Docker application on ordinary laptops. Hosted Gemini inference uses the user's configured key and model. No cloud deployment. Evidence review, source documents, device configuration and policy versions are the working materials.

## Capabilities and Constraints

Single/bulk upload, immutable audits, source-linked findings, mapping tests and review, multiple framework crosswalks, PDFs, tenant isolation and durable processing. Policy content and vendor support are declared rather than universal. No automatic live-device writes. Included configurations are synthetic.

## Evidence on Hand

The approved plan and source statement under docs. Examples must be labelled synthetic. No measured competitive advantage, monthly uptime or full-framework certification exists yet.

## Product Principles

- Evidence before verdicts.
- Unknown is an explicit result.
- Changes are tested and reviewed.
- Useful local operation survives unavailable AI.

## Accessibility & Inclusion

Keyboard operation, readable contrast, visible focus, semantic tables and forms, responsive evidence review. These were included in the approved plan.
