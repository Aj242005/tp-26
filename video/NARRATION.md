# Prooflane: two-minute narration

Introduction first. Plain English. Final narration will use your own Indian English voice through VoiceStudio.

## 0:00-0:09 | Introducing Prooflane

Prooflane checks router and firewall settings, flags security risks, and shows the evidence behind every finding. Here is how it works.

## 0:09-0:17 | One network. Many languages.

Different vendors use different configuration languages. Reviewing them by hand makes security problems easy to miss.

## 0:17-0:27 | Snapshot to assessment.

Upload saved device settings. Add the device type, software version and file completeness. Choose a security checklist, then start the audit.

## 0:27-0:40 | Show me the evidence.

In this sample, line five uses an old version of secure remote access, SSH. The rule requires version two. Prooflane flags the mismatch and suggests a fix for human review.

## 0:40-0:48 | Unknown is a useful answer.

Missing or conflicting evidence stays unknown. The coverage bar shows how much could actually be checked.

## 0:48-0:57 | Inspect. Explain. Export.

Inspect findings beside the original settings, compare what was found with what was expected, and download a shareable report.

## 0:57-1:11 | Unfamiliar syntax? Build understanding.

When a format is unfamiliar, Gemini consults approved references and asks questions. It proposes a rule for reading that format. Tests and a human reviewer must approve it before use.

## 1:11-1:20 | New understanding. Preserved history.

Approved reading rules work without a code deployment. Every audit keeps its original input and rule versions, even when later rules change.

## 1:20-1:28 | Follow the audit in 3D.

Explore the audit in three dimensions. Select any stage to see the recorded evidence behind it.

## 1:28-1:42 | Built for accountable processing.

The interface sends audits to background workers. A database keeps their history. Encrypted storage protects files. Access is controlled by role. Optional AI helps investigate unfamiliar formats.

## 1:42-1:54 | Clear scope. Demonstrated resilience.

Twenty checks cover selected Cisco, Junos and FortiOS settings. Synthetic tests covered sustained load and recovery. Standards crosswalks support review; they do not certify compliance.
