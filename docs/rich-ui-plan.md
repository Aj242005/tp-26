# Rich interface and interaction pass

Scope: the complete existing Evidence Console, preserving its graphite/blue identity, verified product claims, real data, review gates and local deployment. The user requested a much richer and more enjoyable interface; this is a broad amplification of that system.

The overview becomes an interactive evidence workbench. Recent audits select a real stored assessment; its control tiles preview and pin findings, linking directly to the selected finding or the 3D trail. The assessment's values remain authoritative throughout. Counters serve navigation instead of dominating the composition.

Motion thesis:
- Focal interaction: a control selection moves focus through the evidence spectrum and updates the adjacent finding preview. The visual relationship is the finding, its verdict and its recorded input.
- Continuity: the navigation dock has an animated active indicator; focus mode opens more working space. Theme and dock changes use native view transitions where available. Finding panes and tab selections have short, interruptible transitions.
- Feedback: buttons acknowledge presses, arrows follow their action, copy actions confirm success, upload targets respond to drag/drop, and toasts explain outcomes. Search and disclosures expose clear focus and selection states.
- Budget: no ambient particle or WebGL loop, no new animation dependency, no delayed access to content. Routine feedback is 120–220ms; deliberate layout transitions are at most 360ms. OS reduced motion and a persistent in-app motion control disable nonessential motion.
